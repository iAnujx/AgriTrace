## 🌾 AgriChain — Decentralized Agricultural Supply Chain

A trustless, fully on-chain platform connecting farmers and distributors
without any centralized backend.

- 🔐 MetaMask-only authentication
- 🧾 On-chain role registry (Farmer / Distributor / Admin)
- 📦 Batch creation, bidding, and tracking via smart contracts
- 🖼️ IPFS-stored metadata (photos, ratings)
- ⚖️ Role-based dashboards enforced at contract level
- 🚫 Zero Supabase / database dependency

Built with Solidity · Hardhat · ethers.js · React
